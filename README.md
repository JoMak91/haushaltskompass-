# Haushaltskompass

Privates Haushaltsbuch als Web-App: Kontoauszug (CSV) importieren, Buchungen automatisch in Rubriken sortieren, mit Richtwerten für den Haushalt vergleichen und Kostenfallen erkennen.

Alle Finanzdaten bleiben ausschließlich im Browser-Speicher des Geräts. Dieses Repository enthält nur den Programmcode, keine persönlichen Daten.
